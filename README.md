# QUIZ-GAME

## Quiz exam system
A simple console-based Quiz Exam System
built with Python.

## Features
- Start Quiz
- Randomize Questions
- View Question
- Add new Question
- Search Question
- Calculate Quiz Score
- View Quiz Results
- Save Results to a Text File
- Input Validation

## Concepts Used
- Python Lists
- Dictionaries
- Function
- For Loops
- If/Else
- enumarate()
- len()
- isdigite()
- lower()
- append()
- copy()
- random.shuffle()
- File Handiling
- String Formating (f-strings)
  
## How Run
1. Make sure Python is installed.
2. Download or clone this repository.
3. Run The Python file: python quiz.py

## Purpose
This project was created to practice Python programing, problem-solving, functions, loop, data structures, and file handling.
